ISH (Insurance System for Health)

I designed and developed the Insurance System for Health, a full-stack online platform that enables citizens to apply for a range of health and insurance plans tailored to their unique life situations and profiles.

On the backend, I developed RESTful APIs using Java and Spring Boot within a robust microservices architecture, incorporating key components like the Config Server, Eureka Server, API Gateway, and Admin Server to ensure scalability and resilience.

For the frontend, I built a responsive and user-friendly interface using HTML, CSS, and JavaScript, providing a smooth and intuitive experience for users across devices.

I created key application modules, including User Management, Citizen Registration, Data Collection, Eligibility Check, Payment, Plan Administration, and Report Generation, ensuring that all essential functionalities were covered.

To secure the system, I implemented Sign Up/Sign In features for authentication and session management, safeguarding user accounts and ensuring safe access to sensitive data.

I incorporated input validation, auto-generation of application IDs, and automated email confirmations upon successful registration, enhancing system reliability and improving the user experience.

A centralized DC Management Service was developed to handle case creation, plan selection, and data persistence, including income, education, and child details, with built-in validation checks and real-time email alerts.

I also designed an Eligibility Service that assesses user eligibility for programs like SNAP, CCAP, and Medicaid, using submitted case data and personal attributes to determine program fit.

On the administrative side, I developed features that allow for plan updates, assignment of case worker roles, and management of user notifications, streamlining system management for admins.

To ensure consistent deployment and environment parity, I containerized the services using Docker, and deployed them on Render, simplifying the deployment pipeline.

I used Git for version control and collaborated effectively with the team, hosting the project code on GitHub to track progress, manage branches, and enable smooth collaboration.

Finally, I thoroughly documented and tested the APIs using Swagger and Postman, ensuring robust, clear, and reliable communication between system components.
